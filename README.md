# Oasis – Salon & Beauty Studio website

A premium, mobile-first single-page website built with plain HTML, CSS and JavaScript. No build step and no server needed.

## Structure
- `index.html` – page content
- `css/style.css` – design
- `js/script.js` – menu, service tabs, gallery viewer
- `images/` – photos (replace a file and keep the same name to swap it)
- `favicon.svg` – browser tab icon

## Before going live
Replace the sample phone, WhatsApp number, address, email, social links, prices and reviews in `index.html` with the real business details.

## Hosting
GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root).
